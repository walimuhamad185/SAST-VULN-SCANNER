# SAST-VULN-SCANNER 🛡️

A Python-based Static Application Security Testing (SAST) tool designed for Kali Linux. It scans source code files for high-risk vulnerabilities and generates detailed HTML reports.

## 🚀 Features
- **Authentic Scanning:** Zero false-positive core analysis framework.
- **Vulnerability Breakdown:** Identifies critical code execution flaws, injection points, and unsafe functions.
- **Automated HTML Reporting:** Generates clean, client-ready security audit dashboards.

## 🛠️ Installation & Usage
```bash
git clone https://github.com/walimuhamad185/SAST-VULN-SCANNER.git
cd SAST-VULN-SCANNER
python3 sast_agent.py --file <target_file>
```
